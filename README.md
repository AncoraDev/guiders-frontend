# Guiders Frontend

Console (comercial) y Admin (plataforma). Documentación: [docs/README.md](docs/README.md).

## Arrancar

Necesitas el backend en http://localhost:3000.

```bash
npm install              # primera vez
npm run serve            # Console → http://localhost:4200
npm run serve:admin      # Admin  → http://localhost:4201
```

Usuarios locales: [docs/accesos-local.md](docs/accesos-local.md).
