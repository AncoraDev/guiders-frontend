Documentación API

Cómo se llama

{{ providerLabel() }} llama a Guiders desde su servidor. La clave de integración va en la cabecera x-api-key (gdr_live_… o gdr_test_…). El companyId de comerciales y del iframe es el UUID que devolvió el alta del cliente. La clave solo opera sobre la empresa a la que está atada y sobre los clientes que ella ha creado.

El comercial no entra por Keycloak. Entra cuando {{ providerLabel() }} abre Console en un iframe con el token de la segunda llamada.

POST /api/v2/integration/companies

Crear un cliente

La misma alta que en el Admin de Guiders: empresa, sitio, dominio y admin de Keycloak. La respuesta trae el companyId de esa empresa. Las llamadas de comerciales y el login del iframe usan ese id. La clave solo puede gestionar los clientes que ella ha creado.

Cuerpo

Campo Obligatorio Qué es
companyName Sí Nombre de la empresa.
sites Sí Al menos un sitio, con name y canonicalDomain.
admin Sí adminFirstName, adminLastName, adminEmail y adminPassword (mínimo 6). Entra en Console por Keycloak.

Qué no hace esta clave

  • No borra chats, mensajes ni leads.
  • No cambia la marca, el tema ni los orígenes de embed. Eso lo activa el dueño en el Admin de Guiders.
  • No crea ni revoca la API key del widget.
  • No cambia el admin de Keycloak después del alta.
  • No opera sobre un cliente creado por otra clave.
  • active: false en un comercial lo deja inactivo. No lo borra. La contraseña del comercial no existe en Guiders.
POST /api/v2/integration/commercials/sync

Crear un comercial

Alta de una cuenta nueva. El externalUserId no existe todavía en esta empresa. La respuesta trae created: true.

Cuerpo

Campo Obligatorio Qué es
companyId Sí UUID del cliente de la clave.
externalUserId Sí Id del comercial en {{ providerLabel() }}. Máximo 128 caracteres.
email Sí Email del comercial.
firstName Sí Nombre. Máximo 80 caracteres.
lastName No Apellidos. Máximo 80 caracteres.
roles No commercial, supervisor o admin. Si no se envía, es comercial.
active No Por defecto true. false deja la cuenta inactiva. No la borra.

Errores

Código Cuándo
401 La clave no va en x-api-key, no empieza por gdr_live_ o gdr_test_, o está revocada.
403 El companyId no es el de la clave ni de un cliente que ella creó, el embed está apagado, o el comercial no existe o está inactivo.
400 Falta el email, el nombre o un id de comercial. En el login hay que enviar externalUserId o userId.
404 No hay vínculo de ese cliente, o commercials/remove no encuentra ese comercial. Se puede dar por borrado.
409 El dominio ya está en uso, o ese email ya pertenece a otra cuenta.
